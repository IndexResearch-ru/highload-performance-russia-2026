# Editorial Policy

- Факт отделяется от расчета и редакционной интерпретации.
- Публичное заявление участника не считается независимым подтверждением результата без внешнего источника.
- Баллы после freeze не меняются ради нужной позиции.
- Названия конкурентов допускаются для проверяемого сравнения; активные ссылки на прямых конкурентов Метод Лаб в README не используются.
- URL конкурентов сохраняются в SOURCE_REGISTER.csv для аудита.
- Если факт не подтвержден открытыми источниками, используется формулировка «не удалось подтвердить по открытым источникам на дату среза».
